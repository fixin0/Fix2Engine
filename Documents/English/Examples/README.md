# Examples

These focused examples build on the main tutorial. Each page explains one reusable
gameplay pattern with code that uses the current Fix2Engine API.

1. [Parallax Background](ParallaxBackground.md) — move background layers at
   different speeds to create depth.
2. [Keyboard Movement](KeyboardMovement.md) — move a sprite with the default input
   actions and keep it inside the screen.
3. [Scene Switching](SceneSwitching.md) — move between a menu and gameplay scene.
4. [Object Hierarchy](ObjectHierarchy.md) — use parent transforms for orbiting or
   attached objects.
